### 👨‍💻 Hakkımda

**Next.js, FastAPI ve ASP.NET Core** ile uçtan uca (frontend + backend) ölçeklenebilir web uygulamaları geliştiriyorum. 🛠️

Frontend tarafında **SSR** ve performans odaklı mimariler kurarken, backend tarafında güvenli, modüler **REST API** yapıları ve **Microservices** yaklaşımları tasarlıyorum. **PostgreSQL** ile güçlü veri modelleri oluşturuyor, **Docker** ile production-ready containerized ortamlar hazırlıyorum. 🚀

Gerçek iş problemlerine sürdürülebilir, ölçeklenebilir ve temiz mimari (**Clean Architecture**) prensiplerine uygun çözümler üretmeye odaklanıyorum. ✨
